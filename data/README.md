# Popisi riječi i gramatike

- `vocab-n4.json`: riječi JLPT N5 i N4
- `grammar-n3.json`: gramatika JLPT N5, N4 i N3

JLPT nema službene popise. Ovi su neslužbeni i preuzeti skriptom `pipeline/lists.mjs` (`npm run popisi`).
